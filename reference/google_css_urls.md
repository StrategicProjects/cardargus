# Google Fonts CSS API URLs to try for a family

Google Fonts CSS API URLs to try for a family

## Usage

``` r
google_css_urls(family, text = NULL)
```

## Arguments

- family:

  Font family name.

- text:

  Optional normalized character set; when supplied, the `&text=`
  parameter asks the API for a glyph subset.

## Value

Character vector of URLs (css2 and legacy css formats).
