# List available preset card themes

List available preset card themes

## Usage

``` r
card_themes()
```

## Value

Character vector with the names of the preset themes accepted by
[`card_theme()`](https://strategicprojects.github.io/cardargus/reference/card_theme.md)
and by the `theme` argument of
[`svg_card()`](https://strategicprojects.github.io/cardargus/reference/svg_card.md).

## Examples

``` r
card_themes()
#> [1] "default" "light"   "dark"    "slate"   "ocean"   "forest"  "sunset" 
#> [8] "violet" 
```
